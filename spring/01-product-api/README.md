# 01. Product API — 다음 실습

Java 상품·재고 실습을 마친 뒤 같은 요구사항을 HTTP API로 확장할 위치입니다.
아직 Spring 프로젝트나 실행 코드는 생성하지 않았습니다.

예정된 주제:

- 상품 등록, 목록 조회, 재고 변경을 HTTP 요청으로 제공하기
- 요청·응답과 도메인 객체의 책임 구분하기
- Controller와 서비스의 책임 이해하기
- 서비스 테스트와 API 테스트 작성하기
- 이후 database 실습과 연결해 영속성 추가하기

실습을 시작할 때 이 폴더를 독립 Spring Boot 프로젝트로 구성합니다.
루트 멀티모듈이나 Java 실습 프로젝트와의 빌드 의존성은 필요할 때 검토합니다.
