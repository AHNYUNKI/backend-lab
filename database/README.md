# Database — SQL 실습 위치

상품·재고 데이터를 SQL로 다룰 때 사용할 폴더입니다.
아직 데이터베이스 설치, 연결 설정, SQL 정답은 추가하지 않았습니다.

실습을 시작하면 주제별 폴더에 직접 SQL을 작성합니다. 예시:

```text
database/
└── 01-product-sql/
    ├── README.md          # 사용할 DB와 실행 방법
    ├── 01-schema.sql      # 테이블과 제약 조건
    ├── 02-insert.sql      # 상품 등록
    ├── 03-select.sql      # 목록과 조건 조회
    └── 04-update.sql      # 재고 변경
```

기본 키, 자료형, 제약 조건을 먼저 정하고 등록·조회·변경을 검증합니다.
그다음 트랜잭션과 인덱스를 학습합니다. DB 제품과 버전은 실제 실습을 시작할 때 정합니다.
접속 비밀번호와 개인 환경 설정은 저장소에 기록하지 않습니다.
